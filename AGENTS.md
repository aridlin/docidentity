# Document identity policy
All ODT and PDF documents generated by this project must receive a registered `@$` document identifier and a visible Code 128 barcode unless the user explicitly instructs otherwise. Use `docidentity register FILE` for ODF, `docidentity pdf OUTPUT --text TEXT` for a new PDF, or `docidentity export SOURCE OUTPUT.pdf`. Never invent an identifier without committing it to the registry. Test artifacts use an isolated DOCIDENTITY_DATA_HOME and are not production records.

Any user document modification, including formatting, starts one new provisional identity per dirty session. Cursor movement and selection are not modifications. Extension-controlled barcode, metadata and positioning operations preserve identity.

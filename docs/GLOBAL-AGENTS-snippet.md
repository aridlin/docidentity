## Registered document generation
All ODT and PDF documents generated by Codex must receive a registered `@$` document identifier and a visible Code 128 barcode unless I explicitly instruct otherwise. Use the local `docidentity` tooling: `docidentity register FILE.odt`, `docidentity pdf OUTPUT.pdf --text TEXT`, or `docidentity export SOURCE.odt OUTPUT.pdf`. Register ODS and ODP outputs through the same ODF interface when applicable. Preserve the content and verify the visible barcode. Do not invent IDs or claim registration without a successful registry commit. If the tooling is unavailable, report that and fix it before delivering an unregistered document; ask for an exception only if it cannot be made available.
